일반 채팅과 에이전트의 차이

일반 채팅은 그때그때 질문하고 답을 받는 공간입니다. 에이전트는 반복 업무의 목적, 역할, 출력 형식, 금지사항을 미리 정해 두고 같은 기준으로 다시 실행하는 공간입니다.

구분 일반 채팅 에이전트
시작점 질문을 새로 입력 저장된 역할과 지침으로 시작
기억할 것 이번 대화의 맥락 반복해서 지킬 업무 기준
결과 질문마다 달라질 수 있음 정해 둔 형식으로 비교하기 쉬움
사람의 역할 질문을 만들고 답을 확인 목적·기준을 설계하고 결과를 검증

에이전트는 사람을 대신해 최종 결정을 내리는 장치가 아닙니다. 좋은 에이전트는 판단에 필요한 근거·선택지·리스크를 정리하고, 사람이 결정할 지점을 남겨 두는 도구입니다.

  • 확인되지 않은 내용은 확인 필요 또는 추가 자료 필요로 남깁니다.
